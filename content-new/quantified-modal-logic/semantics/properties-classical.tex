\olsection{Properties of classical quantified modal logic}

Classical quantified modal logic, $\Log{CQML}$ has 
the following properties

Necessity of existence is a logical truth
$$\Entails[\Log{CQML}] \lforall[x][\Box\lexists[y][\eq[x][y]]]$$
Equivalently, using $\lfrexists$ for existence:
$$\Entails[\Log{CQML}] \lforall[x][\Box\lfrexists x]$$
