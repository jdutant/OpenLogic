\olsection{Free Logic}


\begin{prob}
    Say whether the arguments below are valid in \emph{negative} free logic.
    If yes, give a natural deduction proof. Otherwise, 
    give a counterexample.
    \begin{enumerate}
        \item $\lforall[x][\Atom{\Obj{G}}{x,b}] \Proves \Atom{\Obj{G}}{a,b}$
        \item $\lforall[x][\Atom{\Obj{G}}{x,b}] \Proves \lexists[y]\lexists[x][\Atom{\Obj{G}}{x,y}]$
    \end{enumerate}

    \begin{ans}
    \begin{enumerate}
    \item$\lforall[x][\Atom{\Obj{G}}{x,b}] \Proves \Atom{\Obj{G}}{a,b}$
    is not valid in any free logic, including \Log{NFL}.
    
    Counterexample in negative semantics. Model $\Struct{M}$
    with domain $D=\{1\}$, $I(G)=\{\tuple{1,1}\}$,
    $I(b)=\{1\}$, and $I(a)$ undefined. Since $I(a)$ is 
    undefined, $\Sat/{M}{\Atom{\Obj{G}}{a,b}}$. However, 
    for any assignment $s$ such that $s(x)$ is defined, 
    $s(x)\in D$ hence $s(x)=1$. Therefore we have $\Sat{M}{\Atom{\Obj{G}}{x,b}}[s]$ for all 
    assigments $s$ such that $s(x)$ is defined, from which
    it follows that 
    $\Sat{M}{\forall[x][\Atom{\Obj{G}}{x,b}]}$. Thus the 
    argument isn't valid and, since \Log{NFL} is 
    sound for negative semantics, not provable in \Log{NFL}.
    
    \item $\lforall[x][\Atom{\Obj{G}}{x,b}] \Proves 
    \lexists[y]\lexists[x][\Atom{\Obj{G}}{x,y}]$ is 
    not valid any free logic, including \Log{NFL}. 

    Counterexample in negative semantics: a !!{structure} with an
    empty domain. $\Struct{M}$ with domain $D=\emptyset$, $I(b)$
    undefined. For every assignement $s$, variable $x$, $s(x)$ is
    undefined. Hence there is no assignment relative to which
    $\Atom{\Obj{G}}{x,y}$ is true, hence
    $\Sat/{M}{\lexists[y]\lexists[x][\Atom{\Obj{G}}{x,y}]}$. However,
    it is vacously true that relative to any assignment \emph{for
    which $s(x)$ is defined}, $\Sat{M}{\Atom{\Obj{G}}{x,b}}[s]$
    (since there is no such assignment). Hence
    $\Sat{M}{\lforall[x][\Atom{\Obj{G}}{x,b}]}$. Thus the argument
    isn't valid and, since \Log{NFL} is sound for negative semantics,
    not provable in \Log{NFL}.

    \emph{Comment. We're considering a !!{structure} in 
    which there is nothing. If there is nothing, it is 
    vacuously true that anything that there is has $G$ to $b$.
    But it is not true that something has $G$ to something.}

    \emph{In the empty domain model every !!{formula}
    $\lforall[v]!A$ is true and every !!{formula} $\lexists[v]!A$
    is false. (This is true in negative semantics but also in 
    positive semantics: you should check it for yourself.) 
    Hence any argument with only $\lforall[v]!A_i$ premises and
    a $\lexists[v]!B$ conclusion is invalid.}

    \emph{How can it be that $\lforall[x][\Atom{\Obj{G}}{x,b}]$ holds
    even though there is nothing, and in particular, no such thing as
    $b$? In the empty !!{structure} of negative semantics, you can't
    assign objects to any variable or constant. So the interpretation
    of each constant is undefined and there's only one assignment $s$,
    for which every variable is undefined. Relative to that
    assignment, $\Atom{\Obj{G}}{x,b}$ is false (because $s(x)$ is
    undefined, and because $I(b)$ is undefined). So, it's \emph{not}
    true that $\Atom{\Obj{G}}{x,b}$ is true relative to \emph{any}
    assignment. Does that mean that $\lforall[x][\Atom{\Obj{G}}{x,b}]$
    is false? No, because the negative semantics clause for $\lforall[v]!A$
    only requires that $!A$ is true relative to any
    assignment \emph{for which $s(v)$ is defined}. Applied to 
    our !!{formula}, it states:}
    \begin{quote}
    \emph{
    $\lforall[x][\Atom{\Obj{G}}{x,b}]$ is true relative to an assignment $s$ iff 
    for every assignment $s^*$ that agrees with $s$ on any variable
    other than $x$, \emph{if} $s^*(x)$ is defined then $\Atom{\Obj{G}}{x,b}$
    is true relative to that assignment. 
    }
    \end{quote}
    \emph{Since we don't have any assignment $s^*$ for which $s^*(x)$ is 
    defined, that is vacuously true.}

    \emph{In positive semantics, we get the same result even 
    though the semantic clauses for $\lforall$ and $\lexists$
    are slightly different. You should check that you understand why.}

    \end{enumerate}

    \clearpage
    \end{ans}
\end{prob}

\olsection{Quantified Modal Logic}

\emph{Notation}. In the following \Log{CQML} (Classical 
Quantified Modal Logic) is quantified modal logic with 
\emph{fixed-domain models}, or equivalently, first-order
logic quantification (as in KCL Philosophical Logic textbook).
You can replace it with Sider's \Log{SQML} (`Simple Quantified Modal Logic')
if you have read the latter instead. The natural deduction for
 \Log{CQML} and \Log{SQML} include all rules of first order logic plus 
modal logic $\Log{K}$.
