\olsection{Variable Domain Quantified Modal Logic Semantics}

The Variable Domain Quantified Modal Logic builds on free logic and,
like free logic, it has a positive and a negative variant. We 
call the positive variant \Log{VDQML^+} or simply \Log{VDQML} and 
the negative variant \Log{VDQML^-}.
